# Gestión de Solicitudes Académicas (TPI – Metodología de Sistemas II)

Módulo acotado que permite registrar solicitudes de estudiantes, clasificarlas por
tipo/prioridad/estado, asignar un responsable, buscar solicitudes y emitir un reporte.

> Este repositorio conserva dos estados con tags: `estado-inicial` (sistema base con
> deuda técnica) y `estado-refactorizado` (versión final). Ver `docs/`.
